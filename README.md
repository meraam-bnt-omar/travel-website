# travel-website

**Travel** is a responsive travel website built using only HTML and CSS. It features destination highlights, promotional offers, and service advantages, making it ideal for a travel agency landing page or portfolio project.

## Introduction

This project includes:

- A navigation bar
- Hero image/banner
- Featured travel destinations
- Promotional section (Why Us)
- Memorable moments gallery
- Documentation and offers
- Footer with branding and links

## Live Demo 

Check out the live demo of the project: [Live Demo Link]- https://travel-website-xabw.onrender.com/

## Features

- Mobile-first design using Flexbox
- Visually appealing layout
- Custom font and color palette
- Image sections with rounded corners
- Sectional page structure for easy reading

## Technologies Used

- HTML

- CSS

- Google Fonts (Gilda Display, Urbanist)

## Usage 

To explore the Travel Website:

1. **Visit the Live Demo**  
   Click the following link to view the site in your browser:  
   [Live Demo] (https://travel-website-xabw.onrender.com/)

2. **Navigation Instructions**  
   - Use the navigation bar to browse through the **Home**, **Destinations**, **why-us**, and **Contact** sections.  
   - Scroll through the homepage to view featured travel destinations and promotions.  

3. **Responsive Design**  
   The website is fully responsive — you can view it on desktops, tablets, and smartphones.
